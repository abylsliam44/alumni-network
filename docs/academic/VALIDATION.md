# Проверка учебного режима

Статус: разработка не завершена; AC-01–16 не следует считать пройденными. Полная автоматическая интеграционная приёмка, полная проверка offline-импорта, полный HTTP benchmark, финальный отчёт и полный комплект скриншотов ещё не готовы. Документы модели и API являются черновиками.

Проверено локально: `docker compose config --quiet`, сборка Compose и старт трёх контейнеров, health readiness, seed с 50 пользователями, 120 проектами, 50 откликами и 550 событиями; login, выборка рекомендаций и повтор одного event_id (201, затем 200). `npm run build` прошёл в контейнере. Общий `npm run lint` завершился ошибкой из-за семи ошибок в существующих файлах вне учебного интерфейса; полный вывод следует повторно получить командой `docker compose --env-file .env.academic -f docker-compose.academic.yml exec frontend npm run lint`.

В Safari вручную проверены вход, каталог и рекомендации; скриншот рекомендаций находится в `screenshots/recommendations.png`. На отдельной MongoDB прошли три интеграционных теста: конкурентный отклик, чужое изменение и повтор события. Остальные критерии и пользовательские сценарии требуют проверки.

Дополнительно: учебный файл `src/Academic.jsx` прошёл отдельный `npx eslint`. Seed содержит старый проект с полным совпадением навыков, который на реальной выдаче оказался первым. Общая совместимость исходного режима, все сценарии AC, импорт и полный HTTP benchmark ещё не проверены.

## Синтетический benchmark MongoDB

Стенд: Apple M1 Pro, 32 ГБ RAM, macOS 27.0.1, Docker 29.1.3, Compose 2.40.3, MongoDB 7.0.45; Python 3.11.18 внутри контейнера. Отдельная база `alumni_academic_benchmark`: 10 000 проектов, 1 000 пользователей, 100 000 событий. По 10 прогревочных и 100 последовательных измерений на запрос. Индексы снимались только с benchmark-копии, ограничения уникальности сохранены.

| Запрос | p95 до индексов, мс | p95 после индексов, мс |
| --- | ---: | ---: |
| Каталог | 6.32 | 0.35 |
| Категория | 3.97 | 0.34 |
| Навыки | 0.32 | 0.40 |
| История | 27.92 | 0.32 |
| Расчёт рекомендаций | 20.19 | 26.62 |

Полные результаты и executionStats: [benchmark.json](benchmark.json). Агрегация обработала все 10 000 документов: после индекса просмотрено также 10 000 ключей. Индекс не ускоряет вычисление score; дополнительный проход по индексу здесь увеличил время. Это измерения синхронных запросов драйвера внутри контейнера, без HTTP, связанных приложений и UI; они не доказывают соблюдение p95 полного пользовательского запроса. Для воспроизведения на уже подготовленной benchmark-базе: `docker compose --env-file .env.academic -f docker-compose.academic.yml exec -T backend python scripts/academic_benchmark.py`. Первоначальное заполнение пустой benchmark-базы выполняется с `--prepare`.

На одноразовых синтетических PostgreSQL и MongoDB dry run импорта не записал данные; два последовательных импорта оставили 2 users, 1 project, 1 application и 1 APPLY без дублей. Повтор после изменения импортированного пользователя завершился с явным конфликтом. Источники и данные были тестовыми; полная проверка импортера, в том числе всех вариантов старых данных, остаётся открытой.
