# Assignment #6 — work report (draft)

**Objective:** build a local NoSQL data layer and project recommendation demonstration for students and alumni.

The academic environment starts MongoDB as a single-node replica set and uses a separate backend and frontend. A reproducible synthetic dataset supports demonstrations. The baseline calculates skill, category and interest scores before pagination; no claim of real-world recommendation improvement is made. See [proposal](PROPOSAL.md), [model](DATA_MODEL.md), [API](API.md), [setup](SETUP.md) and [validation status](VALIDATION.md).

Completed observations and remaining work must be taken from `VALIDATION.md`. Required screenshots and benchmark evidence are incomplete; this draft is not the final submission report.
